# Birthday Proposal — One Page

A simple, premium, static HTML/CSS/JS birthday-to-proposal website.

## Personalize

Open `script.js` and change:

`const HER_NAME = "Her Name";`

## Add your video

Put your video in the same folder as `index.html` and name it:

`birthday-video.mp4`

The site expects an MP4 video.

## Run

You can double-click `index.html` for a quick preview.

For the best local preview in VS Code, use Live Server.

## Deploy to GitHub Pages

Upload `index.html`, `style.css`, `script.js`, and `birthday-video.mp4` to your repository.

Then enable GitHub Pages from Settings → Pages and select your branch.
